# Page Dependency Trees

## `/` — Domuri home page

Entry: `index.html`

Dependencies:

- `index.html`
  - Official Domuri logo Brand Asset URL
  - Residencial Marriot hero/card image Brand Asset URL
  - Inline CSS with responsive header, hero, single property card, contact band, and footer

## `/imovel.html` — Residencial Marriot detail landing page

Entry: `imovel.html`

Dependencies:

- `imovel.html`
  - Google Fonts stylesheet: DM Sans and Instrument Serif
  - Remote property images from `s01.jetimgs.com`
  - Inline CSS
  - Inline JavaScript for reveal animation, gallery modal, focus handling, and WhatsApp lead submission

There are no local component imports, CSS files, JavaScript modules, framework layouts, or router files.
