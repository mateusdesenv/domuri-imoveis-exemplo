# Routes

The project is static HTML served from the repository root. There is no router configuration.

| URL | File | Layout | Summary |
| --- | --- | --- | --- |
| `/` | `index.html` | Inline navigation + footer | Domuri homepage with hero, one featured property card, contact band, and footer. |
| `/imovel.html` | `imovel.html` | Inline navigation + footer | Detailed landing page for Residencial Marriot, property code 55128. |
| `/imovel-alternativo.html` | `imovel-alternativo.html` | Editorial split layout | Alternative detail presentation for the same Residencial Marriot apartment, with editorial hero, facts panel, and WhatsApp CTA. |

## Planned target

The home shows two presentation cards for the same property. The original detailed property experience remains available at `/imovel.html`; the alternate card links to `/imovel-alternativo.html`.
