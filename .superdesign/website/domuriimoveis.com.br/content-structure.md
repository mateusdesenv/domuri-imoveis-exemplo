# Domuri Imobiliária

## Business Context
- **Type/Industry:** Real estate agency (compra e venda de imóveis exclusivos)
- **What they do:** Strategic acquisition and sale of exclusive properties in Gravataí and region
- **Target audience:** Property buyers and sellers in Gravataí metro area, mid-to-premium segment
- **Page goal:** Capture property search intent via filtered form; showcase featured developments and available listings

---

# Page Layout & Structure

### Hero
Cityscape photograph (2.80:1, dusk/golden hour, horizontal skyline bleeding full width) with dark semi-transparent overlay. Centered composition: white h1 "Viva o nível que você merece." + subheading "Atuação estratégica na compra e venda de imóveis" positioned mid-frame. Thin vertical gold accent bar left-of-center. Search form (white background, rounded corners) sits below text as unified block with 3 dropdowns + text input (Pretensão → Comprar, Tipo de imóvel → Todos, Localização → text field) + brown search button (pill-shaped, right-aligned). Secondary link "Buscar por código" below form. No asymmetric floating elements; composition is centered and stacked.

### Header / Navigation
Fixed horizontal bar: logo "Domuri" (left), 4 text links center-left (Comprar | Lançamentos | Institucional | Contato, dark gray), phone icon + "Ver telefones" button (right, brown background). No hamburger visible in desktop view; navigation is vertical-type but displayed horizontally. Sticky to top.

### Primary CTA / Input
Form block within hero: 3 dropdowns (white background, dark gray text) + location text input + brown search button (action: "Pesquisar"). Pills used on confirm button. Focus-visible states present.

### Conheça nossos principais empreendimentos
- **Purpose:** Featured development carousel; set context for premium/new listings
- **Layout:** Bento grid, 3 columns, 4 cards. Cell spans: Mirá (1×1 left), Alphaville (spans 2 cols × 1 row, right). Prado + Arboretto (1×1 each, bottom row). Carousel navigation (prev/next arrows) on Mirá and Alphaville. Each cell shows hero image (1.50:1) + price label + property name + bed/bath/garage specs in white text overlay (bottom-left). Arboretto is image-only (no spec text visible). Carousel dots below each dev.

### Cookie alert
- **Purpose:** GDPR/compliance banner
- **Layout:** Horizontal bar, white background, centered text + brown "Aceitar cookies" button (pill)

### Imóveis para comprar
- **Purpose:** Secondary listing showcase; drive conversion to full listings page
- **Layout:** Uniform grid, 4 columns, 4 equal cards. Each card: property image (1.78:1 thumbnail) with carousel (prev/next, dots below) + type badge (e.g., "Mediação") + property name + address + specs (sqm, beds, baths, garages) + price + "Comprar" button (white text on dark gray or brown background) + heart icon (wishlist, top-right). Link to "Ver todos" (top-right of section).

### Contact map & info card
- **Purpose:** Local presence; drive phone inquiry
- **Layout:** Full-width embedded map (1.50:1) with white info card overlay (center, rounded corners): "Domuri Imobiliária" + address + phone "(51) 98044-8075" centered within.

### Footer
- **Purpose:** Navigation, branding, social, compliance
- **Layout:** Dark background (dark gray or black). 3-column link group (Imóveis, Domuri, Contato, each with 2–4 links). Logo + social icons (Facebook, Instagram) center-left. Copyright + legal links (Política de Privacidade, Termos de Uso) + "Feimob" attribution (bottom-right). All text white or light gray.

---

**Notable patterns:** Bento grid for featured developments (mixed-span mosaic: 1 large cell spans 2 cols). Uniform 4-col grid for property listings. Carousel navigation present on hero cards and listing thumbnails. White form overlaid on dark hero image. Brown (#8B7355 equivalent) used as accent on buttons (search, "Aceitar cookies", property CTAs). Dark gray (#2C2C2C equivalent) on text and secondary surfaces. Rounded corners on form inputs and buttons; pills on action buttons. Focus-visible and prefers-reduced-motion honored throughout.
